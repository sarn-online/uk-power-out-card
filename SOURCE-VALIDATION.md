# April 2026 ESEC source validation

Authoritative input: the official `esec-guidance-april-2026.pdf`. Annex 2 occupies PDF pages 23–40 (printed pages 22–35, with repeated printed page numbers in the original). Each level has 18 load blocks and 56 weekly three-hour periods. Black cells mean disconnected.

The PDF was rendered locally using Apple's PDFKit. All 18,144 cell centres were sampled to extract the Boolean table. The first Annex 2 page has a different table layout from the remaining pages; the extraction uses separate geometry for it. The exact source table is compiled into RotaData.swift, with no runtime downloads or formula extrapolation.

Independent comparison: official accessible Annex 2 workbook linked from the GOV.UK ESEC publication, downloaded 11 November 2026:

The original development workspace retains the source PDF and workbook; this distribution links to their public originals. Source discrepancies are not resolved by assuming the workbook is newer or by altering the PDF's cells.

## Time semantics

Annex 1 states periods 1–8 as 00:30–03:30 through 21:30–00:30. The app displays civil days 00:00–24:00. The first half-hour therefore uses the previous day's last period, including Sunday to Monday. Adjacent identical states are merged for readability. Times always use Europe/London, including while the device is abroad. Duration labels are nominal clock minutes; daylight-saving changes can alter elapsed durations, as explained in the app.

## Verification

`pdf-schedules.json` retains the PDF-extracted cell fixture independently from the compiled string table. The source fixture is public-sector rota data, not household data.

`npm test` compares all 18,144 compiled source cells and all 3,265,920 civil minutes across 324 rota/level scenarios against that fixture. It also exercises UK clock changes, the six-day render, stored preferences and invalid settings. This catches conversion and rendering errors; it does not resolve the six official source disagreements above or establish actual supply.

The original extraction was performed using PDFKit at cell centres, with separate geometry for the first page. The PDF rendering and official accessible spreadsheet were independently compared before packaging. No schedule is generated by an assumed rotation formula.
