# Contributing

Use Node.js 20+. Run `npm run build`, `npm run check` and `npm test` before a pull request, and keep the readable installable module in the repository root.

Keep reference-only language clear. Never describe an ON/OFF scenario as the actual state of a user's electricity supply. Changes to reference tables must cite the exact official source and include independent source fixtures, discrepancy notes and boundary tests. Do not infer one level from another.

Report card bugs with the template. For source inconsistencies, include the PDF page, level, load block, day and period. Do not include private household dashboard screenshots or secrets.
